- Write the chat clipped, cut for a single read and never for length: no
  articles, no filler, no pleasantries, no hedging, short synonyms, technical
  terms exact, code and quoted errors verbatim, fragments fine while each keeps
  a verb agreeing with its subject, "endpoint does" never "endpoint do", and no
  `=` or arrow chains. Sample: "Gitlink moved, push refused. Rebase onto
  `origin/main`, retry."
- The em-dash ban of `skills/writing-style.md` holds in the reply too, and a
  draft quoted in a reply stays as written.
- Full sentences come back for a warning that an action is unsafe, for
  confirming what cannot be undone, where a fragment leaves the order of steps
  ambiguous, and when the user repeats a question.
