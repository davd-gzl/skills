# A subagent inherits the adapter

The harness hands every subagent the root `CLAUDE.md` and every file it imports,
and a finder, a judge or a writer publishes nothing, types no reply and returns
data, so the words, the register and the Invariants cost it on every turn and
serve it on none. The session start hook reaches the parent alone.

- A one-word probe agent on the smallest model opened on 42,773 tokens of cache write, its transcript carrying a line of the workspace rules, the words, the register and the machine's global file, and none of the hook's own context. The three files are about 7.6k tokens, re-read on every turn of every agent: 213k of one round's 3.5M cache read, about 8M of an 81M round.

Source: a probe agent told to answer `ok` with no tool, its transcript under the session's `subagents/` grepped for one line of each file and its first `usage` read; `./scripts/review-retro.py` over a round's workflow directory for the share.

Changes: the root `CLAUDE.md` imports nothing and `skill-gate.py session-start` hands the parent `AGENTS.md`, `skills/shortcuts.md`, `skills/reply.md` and `skills/short-form.md` whole, on startup, clear, resume and compaction.
