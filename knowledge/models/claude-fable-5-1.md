# claude-fable-5-1
Claude Fable 5.1, Anthropic's top generally available tier, above Opus, "for demanding reasoning and long-horizon agentic work", released 2026-09-01; API ID `claude-fable-5-1`, Bedrock `anthropic.claude-fable-5-1`; Claude Mythos 5.1 is the same model, open only to Project Glasswing participants. Source: [Claude Fable 5.1 overview](https://platform.claude.com/docs/en/models/fable-5-1/overview).
- Context window 1M tokens; max output 128K tokens; the Batches 300K beta is not listed for this model. Source: [Claude Fable 5.1 overview](https://platform.claude.com/docs/en/models/fable-5-1/overview).
- Thinking: adaptive, always on, the only thinking mode. Source: [Claude Fable 5.1 overview](https://platform.claude.com/docs/en/models/fable-5-1/overview).
- Effort levels `low`, `medium`, `high`, `xhigh`, `max`; default `high`; per-message effort (beta `mid-conversation-output-config-2026-07-01`) preferred over changing top-level effort, which "steers the model less reliably". Source: [Effort](https://platform.claude.com/docs/en/build-with-claude/effort).
- Forced tool use returns an error; its thinking blocks are unreadable by earlier models; editing earlier turns invalidates thinking blocks. Source: [Claude Fable 5.1 overview](https://platform.claude.com/docs/en/models/fable-5-1/overview).
- Comparative latency "Slower"; knowledge cutoff Jun 2026. Source: [Models overview](https://platform.claude.com/docs/en/about-claude/models/overview).
- Artificial Analysis: 64.7 output tokens/s; 291.45 s time to first token (category median 3.84 s). Source: [Artificial Analysis Fable 5.1](https://artificialanalysis.ai/models/claude-fable-5-1).
- Input $10, output $50, 5-minute cache write $12.50, 1-hour cache write $20, cache read $0.25 (0.025x base input). Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- No long-context surcharge (1M at standard rates); Batch $5 / $25; no fast mode listed; `inference_geo: "us"` adds 1.1x. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- SWE-bench Pro 81.2%, Multilingual 89.1%, Multimodal 54.7%, adaptive thinking at max effort, 5 trials, production safeguards on, 2026-09-01. Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).
- SWE-bench Verified: not reported by Anthropic for this model. Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).
- Terminal-Bench 4.0 55.8% (Mythos 5.1 60.9%), Claude Code `--bare`, max effort, 15 trials per task, ±1.6-2. Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).
- DeepSWE v1.1 67.4%, 5 trials; Anthropic says some failures came from implementing ambiguous tasks more thoroughly than the hidden tests expected. Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).
- FrontierCode 1.1 Main 50.9% at medium effort (Fable 5: 53.5% at xhigh); Extended 63.6% at medium; cheaper per task than Opus 5 at low, medium and high. Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).
- The Opus 5.5 card reports Fable 5.1 FrontierCode Main at 52.8% at its best effort and 50.3% in its summary table. Source: [Claude Opus 5.5 System Card](https://www-cdn.anthropic.com/fc1b44717c85dc068bc6ba5024219938094694bd/Claude%20Opus%205.5%20System%20Card.pdf).
- CursorBench 3.2.0 73.4% (Opus 5: 70.0%); CursorBench 4.0 51.8% (per the Opus 5.5 launch). Source: [Claude Fable 5.1 and Mythos 5.1 launch](https://www.anthropic.com/claude-fable-and-mythos-5-1), [Introducing Claude Opus 5.5](https://www.anthropic.com/news/claude-opus-5-5).
- Vals: LiveCodeBench 90.52% (#1); Terminal-Bench 2.1 85.02% (#2, Terminus 2 harness, fallbacks used); fetched 2026-09-24. Source: [Vals AI](https://www.vals.ai/home), [Vals Terminal-Bench 2.1](https://www.vals.ai/benchmarks/terminal-bench-2-1).

Source: [CodeRabbit: Fable 5.1 model review](https://www.coderabbit.ai/blog/fable-5-1-model-review).

Source: [Huntress: Fable 5.1 API recall](https://www.huntress.com/blog/claude-fable-api-recall).

- ProgramBench, 166 tasks, mini-swe-agent, episodes up to the full 1M window: 87.6% (Opus 5 85.4%, Fable 5 86.3%). Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).

- At `low` effort it calls search and retrieval tools less and answers from memory more than Fable 5. Source: [Prompting Claude Fable 5.1](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1).

Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).

Source: [Claude Fable 5.1 and Mythos 5.1 System Card](https://www-cdn.anthropic.com/0339e6a7c5c7b87f5c07798616dc32c215d14235/Claude%20Fable%205.1%20&%20Claude%20Mythos%205.1%20System%20Card.pdf).
- Anthropic docs: at `xhigh`/`max` it can draft a long deliverable in its thinking and write it out again; fewer progress updates in long tool chains; denser prose; more likely than Fable 5 to rewrite whole files for small edits; open-ended tasks grow scope and add test files. Source: [Prompting Claude Fable 5.1](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1).
- Client-side compaction summaries drop constraints unless told what to keep. Source: [Prompting Claude Fable 5.1](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1).
Inference for review stages (not measured here):
- Finder diff size: no measurement links recall to diff size. Inference: at most about 1,000 changed lines with context per finder, as for Opus. Its ~5 minutes of time to first token and 18-minute reviews make many small finders slow in wall-clock time, so use fewer, larger bundles only where latency does not matter.
- Judge batch: no data. Inference: 3-5 candidates per context, with a nudge to batch independent tool calls, since it may otherwise issue one call per turn in bash loops.
- Effort: finder `low` (CodeRabbit: Low recall 61.0% against 57.1% at High) or `medium`. Judge rerunning a check: `medium`, not `low`, because at `low` it calls tools less and answers from memory. Writer: `low`. Triage: `low`. At 2.5x Opus 5.5's per-token price, with lower Terminal-Bench 4.0, SWE-bench Pro and ProgramBench scores than Opus 5.5 ([Opus 5.5 System Card](https://www-cdn.anthropic.com/fc1b44717c85dc068bc6ba5024219938094694bd/Claude%20Opus%205.5%20System%20Card.pdf)), no measurement here supports it over Opus 5.5 for any review stage.
