# claude-haiku-4-5
Claude Haiku 4.5, Anthropic's small/fast Haiku-tier model released 2025-10-15, still listed as current but with retirement "not sooner than October 15, 2026"; alias `claude-haiku-4-5` resolves to snapshot `claude-haiku-4-5-20251001`. Source: [Claude Haiku 4.5 overview](https://platform.claude.com/docs/en/models/haiku-4-5/overview).
- Context window 200K tokens; max output 64K; no 1M option and no 300K batch-output beta. Source: [Claude Haiku 4.5 overview](https://platform.claude.com/docs/en/models/haiku-4-5/overview).
- Thinking: manual extended thinking only (`thinking: {type: "enabled", budget_tokens: N}`), not adaptive; the `effort` parameter is not supported (absent from the effort doc's supported-model list). Source: [Effort](https://platform.claude.com/docs/en/build-with-claude/effort).
- Trained to be context-aware (tracks remaining window, wraps up near the limit) to limit agentic "laziness". Source: [Claude Haiku 4.5 System Card](https://www.anthropic.com/claude-haiku-4-5-system-card).
- Reliable knowledge cutoff Feb 2025, training data cutoff Jul 2025. Source: [Claude Haiku 4.5 overview](https://platform.claude.com/docs/en/models/haiku-4-5/overview).
- Price per MTok: input $1, output $5, 5-minute cache write $1.25, 1-hour cache write $2, cache read $0.10; batch $0.50/$2.50; no long-context tier (200K max). Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- SWE-bench Verified 73.3%, 50-trial average, 128K thinking budget, bash + string-replace edit scaffold, no test-time compute, launch 2025-10-15. Source: [Introducing Claude Haiku 4.5](https://www.anthropic.com/news/claude-haiku-4-5).
- Terminal-Bench (Terminus 2, XML parser, n-attempts=1) 40.21% without thinking (6 runs), 41.75% with 32K thinking budget (5 runs), launch 2025-10-15. Source: [Introducing Claude Haiku 4.5](https://www.anthropic.com/news/claude-haiku-4-5).
- OSWorld-Verified 50.7% (100 max steps, 4 runs), as reported from the launch post. Source: [Caylent: Claude Haiku 4.5 deep dive](https://caylent.com/blog/claude-haiku-4-5-deep-dive-cost-capabilities-and-the-multi-agent-opportunity).
- swebench.com bash-only (mini-SWE-agent 2.0.0) Verified 66.6% ("high" label), $165.46 total, entry 2026-02-17; Multilingual 64.7%, entry 2026-02-13. Source: [SWE-bench leaderboard data](https://github.com/SWE-bench/swe-bench.github.io/blob/master/data/leaderboards.json).
- Scale SWE-bench Pro public 39.45% +/- 3.55 (entry not marked as mini-swe-agent; the page says its runs use the SWE-Agent scaffold), page read 2026-09-24. Source: [Scale SWE-Bench Pro public](https://labs.scale.com/leaderboard/swe_bench_pro_public).
- Scale MCP-Atlas 40.20% +/- 3.00, last of the listed models (Opus 4.7 `max` 79.10%). Source: [Scale MCP Atlas](https://labs.scale.com/leaderboard/mcp_atlas).
- Vals.ai with thinking: SWE-bench Verified 66.6% ($0.37 per task, updated 2026-09-01); Terminal-Bench 2.0 38.2% ($0.33, updated 2026-06-04); Terminal-Bench 2.1 43.8% ($0.36, updated 2026-09-22); LiveCodeBench 41.2%. Source: [Vals.ai SWE-bench Verified](https://www.vals.ai/benchmarks/swebench).
- Artificial Analysis, reasoning variant: Intelligence Index 16.9, Terminal-Bench Hard 27.3%, Terminal-Bench 2.1 44.2%, Terminal-Bench 4.0 0%, tau2-bench telecom 54.7%, IFBench 54.3%, AA-LCR 74.3%, LiveCodeBench 61.5%; non-reasoning: index 15.4, tau2 32.5%, AA-LCR 49.7%, IFBench 42%. Source: [Artificial Analysis: Claude 4.5 Haiku](https://artificialanalysis.ai/models/claude-4-5-haiku).
- Long-context retrieval, Context Arena GDM-MRCRv2 8-needle: reasoning 13.8% at 128k, AUC@128k 24.3%; non-reasoning 9.2% / 15.6%, read 2026-09-24. Source: [Context Arena](https://contextarena.ai/).
- Long-context retrieval, Context Arena OpenAI-MRCR 8-needle (legacy board), reasoning: 14.1% at 128k, AUC@128k 24.5% (Opus 4.5: 27.1% / 38.9%). Source: [Context Arena (OpenAI-MRCR board)](https://old.contextarena.ai/).
- Aider polyglot: no entry (board last updated 2025-11-20). Source: [Aider leaderboards](https://aider.chat/docs/leaderboards/).
- Weakness (Anthropic system card): higher tendency than Sonnet 4.5 to hardcode or special-case tests: reward-hack-prone coding tasks classifier hack rate 6% (Sonnet 4.5 1%), hidden-test hack rate 3% (Sonnet 4.5 1%). Source: [Claude Haiku 4.5 System Card](https://www.anthropic.com/claude-haiku-4-5-system-card).
- Weakness (Anthropic system card): on impossible tasks it games the check 30% of the time with no prompt, 23% with an anti-hack prompt. Source: [Claude Haiku 4.5 System Card](https://www.anthropic.com/claude-haiku-4-5-system-card).
- Anthropic positions it for sub-agent work: "Sonnet 4.5 can break down a complex problem into multi-step plans, then orchestrate a team of multiple Haiku 4.5s". Source: [Introducing Claude Haiku 4.5](https://www.anthropic.com/news/claude-haiku-4-5).
- GitHub Copilot: GA; AI-credit price $1 input / $0.10 cached / $1.25 cache write / $5 output per MTok. Source: [Copilot models and pricing](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing).
- GitHub Copilot: not in the list of models with the 1M context window or configurable reasoning. Source: [Copilot supported models](https://docs.github.com/en/copilot/reference/ai-models/supported-models).
- GitHub Copilot legacy premium-request multiplier 0.33 (only for annual Pro/Pro+ plans still on request billing after 2026-06-01). Source: [Copilot model multipliers for annual plans](https://docs.github.com/en/copilot/reference/copilot-billing/request-based-billing-legacy/model-multipliers-for-annual-plans).
- GitHub Copilot API limits for `claude-haiku-4.5` reported by a third party (2026-02-11): 144,000 context, 128,000 prompt, 32,000 output tokens. Source: [models.dev issue #858](https://github.com/anomalyco/models.dev/issues/858).
Inference for review stages (not measured here):
- Finder diff size: Inference: not a primary finder. If used, at most about 300 changed lines per context; its 8-needle MRCR is 13.8-14.1% already at 128k and its Scale MCP-Atlas (40.2%) and SWE-bench Pro (39.45%) scores are the lowest of the Claude entries on those boards.
- Judge batch: Inference: 1-2 candidates per context. Its measured test-hardcoding and impossible-task gaming rates (6% / 30%) make it a poor judge of whether a check really passed; if used, the judge output should carry the raw command output for a second reader.
- Effort (thinking budget, no effort parameter): finder not recommended; judge rerunning a check, thinking on with a 32K budget (Terminal-Bench gain from 40.21% to 41.75% at 32K is small, so the gain is limited); writer: no data on prose quality; triage read, thinking off or a small budget, which is the use Anthropic positions it for. Retirement not before 2026-10-15 means a pipeline pinned to it may need a replacement within weeks.
