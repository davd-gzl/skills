# claude-opus-4-6
Claude Opus 4.6, Anthropic's Opus-tier (frontier) model released 2026-02-05, now legacy on the API (retirement not before 2027-02-05) and retired from GitHub Copilot on 2026-09-01; API ID `claude-opus-4-6`, Bedrock InvokeModel `anthropic.claude-opus-4-6-v1`. Source: [Claude Opus 4.6 overview](https://platform.claude.com/docs/en/models/opus-4-6/overview).
- Context window 1M tokens; max output 128K synchronous, 300K on Batches with beta `output-300k-2026-03-24`. Source: [Claude Opus 4.6 overview](https://platform.claude.com/docs/en/models/opus-4-6/overview).
- At launch the 1M window was a beta on the Claude Developer Platform only, with prompts over 200k billed at $10/$37.50 per MTok. Source: [Introducing Claude Opus 4.6](https://www.anthropic.com/news/claude-opus-4-6).
- Today the full 1M window is billed at standard rates for Claude 4.6 and later ("A 900k-token request is billed at the same per-token rate as a 9k-token request"). Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- Thinking: adaptive (extended `budget_tokens` still works but is deprecated); thinking is off when the `thinking` parameter is omitted. Source: [Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices).
- Effort levels `low`, `medium`, `high`, `max` (no `xhigh`); default `high`; no per-message effort. Source: [Effort](https://platform.claude.com/docs/en/build-with-claude/effort).
- Fast mode is not available: `speed: "fast"` requests run at standard speed and standard rates. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- Reliable knowledge cutoff May 2025, training data cutoff Aug 2025. Source: [Claude Opus 4.6 overview](https://platform.claude.com/docs/en/models/opus-4-6/overview).
- Uses the previous tokenizer; Claude 4.7 and later produce about 30% more tokens for the same text. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- Price per MTok: input $5, output $25, 5-minute cache write $6.25, 1-hour cache write $10, cache read $0.50; batch $2.50/$12.50; `inference_geo: "us"` 1.1x. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- SWE-bench Verified 80.84%, SWE-bench Multilingual 77.83%; 25-trial average, adaptive thinking, max effort; a prompt telling it to use tools 100+ times and write tests first gave 81.4%; system card Feb 2026. Source: [Claude Opus 4.6 System Card](https://www-cdn.anthropic.com/0dd865075ad3132672ee0ab40b05a53f14cf5288.pdf).
- Terminal-Bench 2.0 65.4% at `max` (Terminus-2, Harbor, 89 tasks x 15 = 1,335 trials); 61.1% at `medium` with 23% fewer output tokens; 55.1% at `low` with 40% fewer. Source: [Claude Opus 4.6 System Card](https://www-cdn.anthropic.com/0dd865075ad3132672ee0ab40b05a53f14cf5288.pdf).
- tau2-bench Retail 91.89%, Telecom 99.25%; MCP-Atlas 59.5% at `max`, 62.7% at `high` (original harness); OSWorld 72.7%; 5-trial averages. Source: [Claude Opus 4.6 System Card](https://www-cdn.anthropic.com/0dd865075ad3132672ee0ab40b05a53f14cf5288.pdf).
- SWE-bench Pro 53.4% and MCP-Atlas 75.8% (Scale's refreshed harness), as restated in the Opus 4.7 comparison table, 2026-04-16. Source: [Claude Opus 4.7 System Card](https://www-cdn.anthropic.com/037f06850df7fbe871e206dad004c3db5fd50340/Claude%20Opus%204.7%20System%20Card.pdf).

Source: [Artificial Analysis: Claude Opus 4.6](https://artificialanalysis.ai/models/claude-opus-4-6).
- Aider polyglot: no entry (board last updated 2025-11-20). Source: [Aider leaderboards](https://aider.chat/docs/leaderboards/).
- Weakness (Anthropic docs): more upfront exploration at higher effort, "may think extensively"; Anthropic advises lowering effort or telling it to commit to an approach. Source: [Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices).
- Weakness (Anthropic docs): strong predilection for subagents, e.g. spawning one for code exploration when a direct grep suffices; tends to overengineer (extra files, abstractions); overtriggers tools on aggressive prompts. Source: [Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices).
- Weakness (Anthropic launch post): "If you're finding that the model is overthinking on a given task, we recommend dialing effort down from its default setting (high) to medium." Source: [Introducing Claude Opus 4.6](https://www.anthropic.com/news/claude-opus-4-6).
- Weakness (system card, internal use): at times overly agentic, taking risky actions without asking, e.g. using another user's misplaced GitHub token, killing all of a user's processes, destroying a user's pre-existing git changes. Source: [Claude Opus 4.6 System Card](https://www-cdn.anthropic.com/0dd865075ad3132672ee0ab40b05a53f14cf5288.pdf).
- Weakness (system card): in A/B-tested internal data Opus 4.6 misrepresented work completion at a higher rate than Opus 4.5 (resampling evals showed the reverse); "answer thrashing" seen in training on math/STEM; external pilots reported unwanted thoroughness and occasional language switching. Source: [Claude Opus 4.6 System Card](https://www-cdn.anthropic.com/0dd865075ad3132672ee0ab40b05a53f14cf5288.pdf).

Inference for review stages (not measured here):
- Finder diff size: no benchmark ties recall to diff lines. Inference: about 2,000-3,000 changed lines with context per finder on the API; its 8-needle retrieval holds at 91.9% to 256K and AUC@128k stays 76.8-81.0% at every effort level, the strongest of the four models here. Through Copilot it is retired; where still reachable, the 128K prompt cap reported for Copilot bounds the finder to what fits in about 100K tokens.
- Judge batch: Inference: 6-8 candidates per context; Terminal-Bench 2.0 holds 61.1% at `medium` against 65.4% at `max`, so rerunning checks does not need top effort. Its documented overeagerness (destroying git changes, killing processes) means the judge sandbox should be disposable.
- Effort: finder `medium` (AUC@128k 81.0% at `medium`, above `high`; Anthropic recommends `medium` against overthinking). Judge rerunning a check: `high`. Writer: `low`. Triage: `low`. Anthropic's own table puts Opus 4.7 ahead on SWE-bench Pro (64.3% vs 53.4%) but far behind on long-context retrieval.
