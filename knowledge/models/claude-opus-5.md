# claude-opus-5
Claude Opus 5, Anthropic's Opus-tier model released 2026-07-24, now legacy (superseded by Opus 5.5 on 2026-09-22, retirement not before 2027-07-24); API ID `claude-opus-5`, Bedrock `anthropic.claude-opus-5`. Source: [Claude Opus 5 overview](https://platform.claude.com/docs/en/models/opus-5/overview).
- Context window 1M tokens, the default and the maximum; max output 128K synchronous, 300K on Batches with beta `output-300k-2026-03-24`. Source: [Claude Opus 5 overview](https://platform.claude.com/docs/en/models/opus-5/overview).
- Thinking: adaptive, on by default; can be disabled (`thinking: {"type": "disabled"}`) only at effort `high` or below; at `xhigh`/`max` disabling returns a 400. Source: [Effort](https://platform.claude.com/docs/en/build-with-claude/effort).
- Effort levels `low`, `medium`, `high`, `xhigh`, `max`; default `high`; per-message effort (beta `mid-conversation-output-config-2026-07-01`) supported. Source: [Effort](https://platform.claude.com/docs/en/build-with-claude/effort).
- Forced tool use (`tool_choice` `any`/`tool`) still accepted: 406-token tool system prompt against 286 for `auto`. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- Reliable knowledge cutoff May 2026. Source: [Claude Opus 5 overview](https://platform.claude.com/docs/en/models/opus-5/overview).
- Input $5, output $25, 5-minute cache write $6.25, 1-hour cache write $10, cache read $0.50. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- No long-context surcharge (1M at standard rates); Batch $2.50 / $12.50; fast mode $10 / $50; `inference_geo: "us"` adds 1.1x. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- SWE-bench Verified 96.0%, averaged over 5 trials, adaptive thinking at max effort, Anthropic internal, 2026-07-24. Source: [Claude Opus 5 System Card](https://www-cdn.anthropic.com/ceaf5c7ff2783855203fde8208ec311252dced5b/Claude%20Opus%205%20System%20Card.pdf).
- SWE-bench Verified 97.00%, #1 of 86, minimal bash-only harness, run by Vals (benchmark now archived); fetched 2026-09-24. Source: [Vals SWE-bench](https://www.vals.ai/benchmarks/swebench).
- SWE-bench Pro 79.2%, Multilingual 89.5%, Multimodal 59.4%, max effort, 5 trials, 2026-07-24. Source: [Claude Opus 5 System Card](https://www-cdn.anthropic.com/ceaf5c7ff2783855203fde8208ec311252dced5b/Claude%20Opus%205%20System%20Card.pdf).
- DeepSWE v1.1 68.8%; FrontierCode 1.1 Main 53.4%; FrontierBench v0.1 43.3% (Harbor's run); max effort, 2026-07-24. Source: [Claude Opus 5 System Card](https://www-cdn.anthropic.com/ceaf5c7ff2783855203fde8208ec311252dced5b/Claude%20Opus%205%20System%20Card.pdf).

Source: [Claude Opus 5.5 System Card](https://www-cdn.anthropic.com/fc1b44717c85dc068bc6ba5024219938094694bd/Claude%20Opus%205.5%20System%20Card.pdf).
- Vals: Terminal-Bench 2.1 84.64% (Terminus 2 harness, used fallback models on some tasks); ProgramBench 3.00% fully resolved; fetched 2026-09-24. Source: [Vals AI](https://www.vals.ai/home), [Vals Terminal-Bench 2.1](https://www.vals.ai/benchmarks/terminal-bench-2-1).

- Internal users (per the system card): self-correction loops, re-verifying already verified answers, especially at higher effort. Source: [Claude Opus 5 System Card](https://www-cdn.anthropic.com/ceaf5c7ff2783855203fde8208ec311252dced5b/Claude%20Opus%205%20System%20Card.pdf).
- AA-Omniscience: accuracy 11% higher than Opus 4.8, hallucination rate 6% higher; net score 0.49. Source: [Claude Opus 5 System Card](https://www-cdn.anthropic.com/ceaf5c7ff2783855203fde8208ec311252dced5b/Claude%20Opus%205%20System%20Card.pdf).
- Anthropic docs: explicit verification instructions cause over-verification; it widens task scope; it delegates to subagents readily; replies and written files run longer than prior Opus, and lowering effort does not shorten visible output. Source: [Prompting Claude Opus 5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5).
Inference for review stages (not measured here):
- Finder diff size: no measurement links recall to diff size. Inference: at most about 1,000 changed lines with context per finder, matching the ~60k-token input per review that CodeRabbit measured with precision holding at 39.3%.
- Judge batch: no data. Inference: 3-5 candidates per context. Do not tell it to re-verify, which docs say causes over-verification and which testers report as self-correction loops.
- Effort: finder `medium` (docs say review accuracy holds at lower effort; testers report worse results at higher effort), with no severity filter in the prompt. Judge rerunning a check: `high`, the default. Writer: `low` with an explicit length instruction, since effort does not shorten its output. Triage: `low`. Opus 5.5 is cheaper per token ($4/$20 against $5/$25) and scores higher on every shared benchmark above.
