# claude-sonnet-5
Claude Sonnet 5, Anthropic's Sonnet-tier (mid) model released 2026-06-30, current (retirement not before 2027-06-30); API ID `claude-sonnet-5`, Bedrock `anthropic.claude-sonnet-5`. Source: [Claude Sonnet 5 overview](https://platform.claude.com/docs/en/models/sonnet-5/overview).
- Context window 1M tokens, both the default and the maximum (no smaller variant); max output 128K synchronous, 300K on Batches with beta `output-300k-2026-03-24`. Source: [What's new in Claude Sonnet 5](https://platform.claude.com/docs/en/models/sonnet-5/whats-new-sonnet-5).
- Thinking: adaptive, on by default; `thinking: {type: "disabled"}` turns it off; manual `budget_tokens` returns 400; non-default `temperature`/`top_p`/`top_k` return 400; prefill returns 400. Source: [What's new in Claude Sonnet 5](https://platform.claude.com/docs/en/models/sonnet-5/whats-new-sonnet-5).
- Effort levels `low`, `medium`, `high`, `xhigh`, `max`; default `high` on the API and Claude Code; `xhigh` recommended for the hardest coding and agentic tasks; no per-message effort (top-level change restarts the cache). Source: [Effort](https://platform.claude.com/docs/en/build-with-claude/effort).
- Anthropic's mapping: Sonnet 5 `medium` is comparable to Sonnet 4.6 `high`, Sonnet 5 `high` comparable to Sonnet 4.6 `max`; "some risk of under-thinking" at `low` on moderately complex tasks. Source: [Prompting Claude Sonnet 5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5).
- New tokenizer: about 30% more tokens than Sonnet 4.6 for the same text (launch post: 1.0-1.35x by content type). Source: [What's new in Claude Sonnet 5](https://platform.claude.com/docs/en/models/sonnet-5/whats-new-sonnet-5).
- Reliable knowledge cutoff Jan 2026. Source: [Models overview](https://platform.claude.com/docs/en/about-claude/models/overview).
- Price per MTok: input $2, output $10, 5-minute cache write $2.50, 1-hour cache write $4, cache read $0.20; batch 50% off; 1M window at standard rate (no long-context surcharge); `inference_geo: "us"` 1.1x. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).
- The $2/$10 launch price, first announced as introductory through 2026-08-31, is now standard; the scheduled rise to $3/$15 will not happen. Source: [Pricing](https://platform.claude.com/docs/en/about-claude/pricing).

- Weakness (Anthropic docs): literal instruction following; a review prompt saying "only report high-severity issues" or "be conservative" lowers measured recall because the model finds bugs but does not report those under the stated bar; Anthropic gives a coverage-first finder prompt. Source: [Prompting Claude Sonnet 5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5).
- Weakness (Anthropic docs): at `high`/`xhigh`/`max` adaptive thinking can fill `max_tokens`, giving a truncated answer with `stop_reason: "max_tokens"`; large system prompts can trigger more thinking. Source: [Prompting Claude Sonnet 5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5).
- Weakness (Anthropic docs): more agentic than Sonnet 4.6, reaches for tools and self-verification loops more readily; with thinking off it is less likely to call tools. Source: [Prompting Claude Sonnet 5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-sonnet-5).
- Weakness (system card, internal and external users): overly literal instruction following, excessive hedging, oversensitivity to suspected prompt injection, occasional hallucinations, overeager workarounds when tools are withheld, brief "glitchy" language-switching sequences. Source: [Claude Sonnet 5 System Card](https://www-cdn.anthropic.com/283ef97c476cf442c91d9a37d5b214242a55bb92/Claude%20Sonnet%205%20System%20Card.pdf).
- Weakness (system card): thinking can devolve into hallucinated system/user interruptions after an ill-formed tool call written in thinking; the training run "was flagged as unhealthy in its second half". Source: [Claude Sonnet 5 System Card](https://www-cdn.anthropic.com/283ef97c476cf442c91d9a37d5b214242a55bb92/Claude%20Sonnet%205%20System%20Card.pdf).
- AA-Omniscience (system card): incorrect-rate 26.5%, declines 26.6% of questions, lowest correct-rate (46.9%) of the compared Claude models. Source: [Claude Sonnet 5 System Card](https://www-cdn.anthropic.com/283ef97c476cf442c91d9a37d5b214242a55bb92/Claude%20Sonnet%205%20System%20Card.pdf).

Inference for review stages (not measured here):
- Finder diff size: no benchmark ties recall to diff lines. Inference: about 1,500 changed lines plus surrounding context per finder, keeping input under 128k where Context Arena still shows 52.9% at 128k (8-needle) and AUC falls to 33.8% by 1M; SWE-bench Pro reference patches average 107 lines over 4.1 files and Sonnet 5 solves 63.2% of them.
- Judge batch: no data. Inference: 4-6 candidates per context, each rerun kept in its own tool call; Terminal-Bench 2.1 (80.4% at `xhigh`) supports running checks, but the card's reports of hallucinated interruptions after bad tool calls argue for short contexts.
- Effort: finder `high` with Anthropic's coverage-first prompt (literal model drops sub-bar findings otherwise). Judge rerunning a check: `xhigh` (Anthropic's recommendation for hard coding; TB 2.1 measured there), with large `max_tokens`. Writer: `medium`. Triage: `low` (Anthropic flags under-thinking risk at `low` only on moderately complex tasks).
