# glm-5.1
Z.ai (Zhipu) flagship open-weight MoE (754B, MIT) for agentic engineering, API id `glm-5.1`, in OpenCode as `opencode/glm-5.1` (Zen) and `opencode-go/glm-5.1`; open-weight release 2026-04-07, superseded by GLM-5.2 (2026-06) and GLM-5.3.
- Release: models.dev lists 2026-04-07 (zai provider) and 2026-03-27 (zhipuai provider); Wikipedia cites a launch article dated 8 April 2026. Source: [models.dev api.json](https://models.dev/api.json), [GLM (AI), Wikipedia](https://en.wikipedia.org/wiki/GLM_(AI)).
- Parameters 754B MoE, BF16/F32, MIT license. Source: [zai-org/GLM-5.1, Hugging Face](https://huggingface.co/zai-org/GLM-5.1).
- Context 200K tokens, max output 128K tokens on the Z.ai API. Source: [GLM-5.1 overview, Z.ai docs](https://docs.z.ai/guides/llm/glm-5.1).
- OpenCode Zen `glm-5.1`: context 204,800, output 131,072, reasoning option "toggle" (on/off only, no effort variants), text in/out. Source: [models.dev api.json, provider opencode](https://models.dev/api.json).
- OpenCode Go `glm-5.1`: context 202,752, output 32,768, no reasoning options listed. Source: [models.dev api.json, provider opencode-go](https://models.dev/api.json).
- Thinking: `thinking: {type: "enabled" | "disabled"}`, enabled by default; `clear_thinking: false` turns on Preserved Thinking; `reasoning_effort` is documented only for GLM-5.2 and above. Source: [Deep Thinking, Z.ai docs](https://docs.z.ai/guides/capabilities/thinking), [Thinking mode, Z.ai docs](https://docs.z.ai/guides/capabilities/thinking-mode).
- OpenCode deliberately returns no variants for GLM-5.1 (binary thinking toggle only), per the fix merged 2026-06-20. Source: [opencode PR #32446](https://github.com/anomalyco/opencode/pull/32446).
- Price, Z.ai API, per 1M tokens: input $1.40, cached input $0.26, cache storage "limited-time free", output $4.40; no long-context tier listed. Source: [Pricing, Z.ai docs](https://docs.z.ai/guides/overview/pricing).
- Price, OpenCode Zen: input $1.40, output $4.40, cached read $0.26, cached write not listed. Source: [OpenCode Zen docs](https://opencode.ai/docs/zen).
- OpenCode Go ($10/month plan): same per-token rates, about 880 requests per 5 h, 2,150 per week, 4,300 per month. Source: [OpenCode Go docs](https://opencode.ai/docs/go).
- SWE-Bench Pro 58.4, vendor-reported, harness and settings not stated on the model card, 2026-04. Source: [zai-org/GLM-5.1, Hugging Face](https://huggingface.co/zai-org/GLM-5.1).
- Terminal-Bench 2.0 63.5 with Terminus-2; 69.0 with Claude Code (best self-reported), vendor-reported. Source: [zai-org/GLM-5.1, Hugging Face](https://huggingface.co/zai-org/GLM-5.1).
- NL2Repo 42.7, CyberGym 68.7, BrowseComp 68.0 (79.3 with context management), vendor-reported. Source: [zai-org/GLM-5.1, Hugging Face](https://huggingface.co/zai-org/GLM-5.1).
- Tool use, vendor: τ³-Bench 70.6, MCP-Atlas public set 71.8, Tool-Decathlon 40.7. Source: [zai-org/GLM-5.1, Hugging Face](https://huggingface.co/zai-org/GLM-5.1).
- MCP Atlas (Scale, independent) 75.6 ±2.7, rank 3. Source: [MCP Atlas leaderboard, Scale Labs](https://labs.scale.com/leaderboard/mcp_atlas).
- Vals Index 52.45% (index version of 2026-06), #1 open-weight at its 2026-04-07 evaluation; temperature 1, top_p 0.95, 131k max output, native GLM API, $0.22/test then. Source: [Vals AI: GLM 5.1](https://www.vals.ai/models/zai_glm-5.1), [Vals AI: GLM 5.2](https://www.vals.ai/models/zai_glm-5.2).
- Code review, AACR-Bench (200 PRs, 50 repos, 10 languages, 1,505 expert comments), OpenCodeReview system with GLM-5.1: SEM-F1 20.4%, precision 28.9%, recall 15.7%, 743K tokens and 4 min 11 s per sample, published 2026-08-10. Source: [OpenCodeReview, arXiv 2608.09290](https://arxiv.org/html/2608.09290v1).
- Artificial Analysis Intelligence Index v4.3.2: 26 (Reasoning variant), 140M output tokens to run the index, 35.3 tokens/s; AA calls it "notably slow and somewhat verbose"; marked deprecated. Source: [GLM-5.1, Artificial Analysis](https://artificialanalysis.ai/models/glm-5-1).
- SWE-bench (swebench.com), Aider polyglot, Terminal-Bench (tbench.ai), LiveCodeBench, Context Arena MRCR: no data found for GLM-5.1. Source: [SWE-bench](https://www.swebench.com/), [Aider leaderboards](https://aider.chat/docs/leaderboards/), [tbench.ai](https://www.tbench.ai/leaderboard/terminal-bench/2.1), [Context Arena](https://contextarena.ai/).
- Long-context retrieval (MRCR, RULER, AA-LCR score for this model): no data found. Source: [AA-LCR, Artificial Analysis](https://artificialanalysis.ai/evaluations/artificial-analysis-long-context-reasoning).
- Weakness: tool calls intermittently fail to parse near a full window (~200k of 202,752) when served by vLLM behind Claude Code; attributed to parser streaming bugs that worsen near the limit; reported 2026-05-12 by a vLLM user, open. Source: [vllm issue #42400](https://github.com/vllm-project/vllm/issues/42400).
- Weakness (by comparison): Z.ai reports GLM-5.2 shows more reward-hacking behaviour than GLM-5.1, and an OpenClaw user found GLM-5.1 free of the tool-result-as-image bug that hits GLM-5.2 after 75+ tool results. Source: [GLM-5.2 blog, Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog), [zai-org/GLM-5 issue #110](https://github.com/zai-org/GLM-5/issues/110).
Inference for review stages (not measured here):
- Finder diff size: about 400 to 500 changed lines per finder, keeping one context under about 100K tokens; the measured failures cluster near the 200K limit and no retrieval-versus-length curve exists for this model. Basis: [vllm issue #42400](https://github.com/vllm-project/vllm/issues/42400), [Z.ai docs](https://docs.z.ai/guides/llm/glm-5.1).
- Judge batch: 3 to 4 candidates per context; low review precision (28.9% on AACR-Bench) means many candidates to reject, and each rerun adds tool output toward the window. Basis: [arXiv 2608.09290](https://arxiv.org/html/2608.09290v1).
- Effort: only thinking on/off exists (no levels in the API or OpenCode). Finder on, judge on, writer on, triage off acceptable; no measurement of thinking-off quality on review tasks found. Basis: [Z.ai thinking docs](https://docs.z.ai/guides/capabilities/thinking), [models.dev](https://models.dev/api.json).
