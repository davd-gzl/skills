# glm-5.2
Z.ai (Zhipu) flagship open-weight MoE (753B total, 40B active per Artificial Analysis; MIT) for long-horizon coding with a 1M window, API id `glm-5.2`, in OpenCode as `opencode/glm-5.2` (Zen) and `opencode-go/glm-5.2`; launched 2026-06-13, weights 2026-06-16, since superseded by GLM-5.3.
- Release: models.dev lists 2026-06-13; Artificial Analysis lists 2026-06-16; Wikipedia cites a launch article dated 15 June 2026; the Hugging Face blog is dated 2026-06-17. Source: [models.dev api.json](https://models.dev/api.json), [GLM-5.2, Artificial Analysis](https://artificialanalysis.ai/models/glm-5-2), [GLM (AI), Wikipedia](https://en.wikipedia.org/wiki/GLM_(AI)), [GLM-5.2 blog, Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog).
- Context 1M tokens, max output 128K, text in/out, on the Z.ai API. Source: [GLM-5.2 overview, Z.ai docs](https://docs.z.ai/guides/llm/glm-5.2).
- In Claude Code the 1M window needs the model name `GLM-5.2[1m]`. Source: [GLM-5.2 blog, Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog).
- OpenCode Zen and Go `glm-5.2`: context 1,000,000, output 131,072, reasoning option effort with values `high`, `max`. Source: [models.dev api.json, providers opencode and opencode-go](https://models.dev/api.json).
- OpenCode variants `high` (sets `reasoningEffort: "high"`) and `max` (sets `reasoningEffort: "max"`), added by the fix merged 2026-06-20; before it OpenCode 1.17.7 exposed no variants for any id containing "glm". Source: [opencode PR #32446](https://github.com/anomalyco/opencode/pull/32446), [opencode issue #32444](https://github.com/anomalyco/opencode/issues/32444).
- API effort: `reasoning_effort` accepts `max` (default, recommended), `xhigh`, `high`, `medium`, `low`, `minimal`, `none`; `none`/`minimal` stop thinking, `low`/`medium` map to `high`, `xhigh` maps to `max`; so two real levels, High and Max. Thinking toggle is `thinking: {type: "enabled" | "disabled"}`. Source: [Deep Thinking, Z.ai docs](https://docs.z.ai/guides/capabilities/thinking).
- Z.ai recommends Max effort for coding tasks. Source: [Z.ai on X](https://x.com/Zai_org/status/2065704921283080538).
- High vs Max measured comparison: no data found (DataCamp, 2026-06-16, found none published). Source: [GLM-5.2 guide, DataCamp](https://www.datacamp.com/blog/glm-5-2).
- Price, Z.ai API, per 1M tokens: input $1.40, cached input $0.26, cache storage "limited-time free", output $4.40; no long-context tier listed. Source: [Pricing, Z.ai docs](https://docs.z.ai/guides/overview/pricing).
- Price, OpenCode Zen: input $1.40, output $4.40, cached read $0.26, cached write not listed, no context tier. Source: [OpenCode Zen docs](https://opencode.ai/docs/zen).
- OpenCode Go ($10/month plan): same rates, about 880 requests per 5 h, 2,150 per week, 4,300 per month. Source: [OpenCode Go docs](https://opencode.ai/docs/go).
- GLM Coding Plan: GLM-5.2 consumes quota at 3x in peak hours (14:00-18:00 UTC+8) and 2x off-peak. Source: [GLM-5.2 blog, Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog).
- SWE-bench Pro 62.1, OpenHands, temperature 1, top_p 1, 32k max new tokens, 400K context, vendor-reported 2026-06. Source: [zai-org/GLM-5.2, Hugging Face](https://huggingface.co/zai-org/GLM-5.2).
- Terminal-Bench 2.1 81.0 with Terminus-2 (256K context, 500 episodes, 4 h timeout); 82.7 with Claude Code 2.1.167 (128k max output, averaged over runs), vendor-reported. Source: [zai-org/GLM-5.2, Hugging Face](https://huggingface.co/zai-org/GLM-5.2).
- DeepSWE 46.2 (mini-swe-agent, 2 h timeout, 400K context); FrontierSWE dominance 74.4 and SWE-Marathon 13.0, both run by third parties at 1M context, max effort, 128K output. Source: [zai-org/GLM-5.2, Hugging Face](https://huggingface.co/zai-org/GLM-5.2).
- Tool use, vendor: MCP-Atlas public set 76.8 (think mode, 10 min per task, Gemini judge), Tool-Decathlon 48.2. Source: [zai-org/GLM-5.2, Hugging Face](https://huggingface.co/zai-org/GLM-5.2).
- MCP Atlas (Scale, independent) 77.8 ±2.6, rank 3, entry dated 2026-07-20. Source: [MCP Atlas leaderboard, Scale Labs](https://labs.scale.com/leaderboard/mcp_atlas).
- Vals AI, 2026-06-17, max effort, temperature 1, top_p 0.95, up to 131k output, native Z.ai API: SWE-bench Verified 82.80% (#3 overall), Terminal-Bench 2.1 67.79%, Vals Index 65.02% then (53.12% ±1.18 on the current index, rank 31/65), $2.08/test. Source: [Vals AI: GLM 5.2](https://www.vals.ai/models/zai_glm-5.2).
- Moonshot's comparison table (Kimi K3 release, 2026-07) cites GLM-5.2 max: Terminal-Bench 2.1 82.7, DeepSWE 46.2, AA-LCR 71.3, MCP-Atlas 82.6. Source: [MoonshotAI/Kimi-K3 README](https://github.com/MoonshotAI/Kimi-K3).
- Long-context retrieval, Braintrust, AST-derived retrieval over the CPython stdlib: 83.3% at 25K, 84.5% at 50K (flat), vs Opus 4.8 87.0%/87.9%, 2026-06-30. Source: [GLM-5.2 vs Opus 4.8 long-context retrieval, Braintrust](https://www.braintrust.dev/evals/glm-52-vs-opus-48-long-context-retrieval).
- MRCR, RULER, retrieval at 500K-1M: no data found; Z.ai's blog reports none. Source: [GLM-5.2 blog, Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog).
- Bug finding, Semgrep IDOR benchmark: F1 39% at about $0.17 per vulnerability found, prompt-only Pydantic AI harness, 2026-06-22; in Semgrep's 2026-07-22 rerun, guided prompt P 0.863 / R 0.238 / F1 0.345, Semgrep Multimodal harness P 0.630 / R 0.540 / F1 0.581. Source: [Semgrep: GLM 5.2 cyber benchmarks](https://semgrep.dev/blog/2026/we-have-mythos-at-home-glm-52-beats-claude-in-our-cyber-benchmarks/), [Semgrep: Kimi K3 precision](https://semgrep.dev/blog/2026/kimi-k3s-code-security-results-lack-precision/).
- Artificial Analysis Intelligence Index v4.3.2: 34 (max), 180M output tokens to run it, 69.1 tokens/s, $0.96 per index task, Omniscience index 4.4; AA calls it "somewhat verbose"; marked deprecated. Source: [GLM-5.2, Artificial Analysis](https://artificialanalysis.ai/models/glm-5-2).
- SWE-bench (swebench.com), Scale SWE-Bench Pro, Aider polyglot, tbench.ai, LiveCodeBench, Context Arena: no GLM-5.2 entry found. Source: [SWE-bench](https://www.swebench.com/), [SWE-Bench Pro V2, Scale Labs](https://labs.scale.com/leaderboard/swe_bench_pro_public_v2), [Aider leaderboards](https://aider.chat/docs/leaderboards/), [tbench.ai](https://www.tbench.ai/leaderboard/terminal-bench/2.1), [Context Arena](https://contextarena.ai/).
- Weakness, reported by Z.ai: GLM-5.2 "shows more potential hacking behavior than GLM-5.1" in coding RL. Source: [GLM-5.2 blog, Hugging Face](https://huggingface.co/blog/zai-org/glm-52-blog).
- Weakness, reported by an OpenClaw user on api.z.ai, 2026-07-11, open: after about 75-100 accumulated tool results the model emits tool results as image content blocks instead of text; absent at 7 results, absent on GLM-5.1. Source: [zai-org/GLM-5 issue #110](https://github.com/zai-org/GLM-5/issues/110).
- Weakness in OpenCode Go: `opencode-go/glm-5.2` advertised 1M but routed to 262,144-token backends, sessions died near 230K input, overflow not classified for auto-compaction; reported 2026-07-12, closed not planned. Source: [opencode issue #36481](https://github.com/anomalyco/opencode/issues/36481).
Inference for review stages (not measured here):
- Finder diff size: about 600 to 800 changed lines per finder, holding one context under about 200K tokens; retrieval is measured flat only to 50K, and OpenCode Go's backend caps near 262K. Basis: [Braintrust](https://www.braintrust.dev/evals/glm-52-vs-opus-48-long-context-retrieval), [opencode issue #36481](https://github.com/anomalyco/opencode/issues/36481).
- Judge batch: 4 to 5 candidates per context, keeping total tool results well below the 75 where the content-block bug starts; high IDOR precision (0.863 guided) suggests fewer false candidates to clear. Basis: [zai-org/GLM-5 issue #110](https://github.com/zai-org/GLM-5/issues/110), [Semgrep](https://semgrep.dev/blog/2026/kimi-k3s-code-security-results-lack-precision/).
- Effort: finder `max` (vendor's coding recommendation, all third-party coding scores at max), judge rerunning a check `max` (no High-vs-Max data to justify less, and reward-hacking risk argues for the deeper setting), writer `high`, triage `high`. Basis: [Z.ai on X](https://x.com/Zai_org/status/2065704921283080538), [Vals AI](https://www.vals.ai/models/zai_glm-5.2).
