# Two versions run at once

A guarantee a change moves from read time to a boot-time sweep or a one-shot job is open for as long as the previous version keeps writing.

- Three review rounds and two simplify passes over one branch read one tree, one process, one version, and missed that a pod on the previous image writes the old shape after the new pods have swept it; a bot reviewer found it first.
- Every angle the review named was a property of the tree, and none a property of the rollout.
